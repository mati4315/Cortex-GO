Respaldo local de SQLite

Crea una copia validada de la base local o restaura un archivo de respaldo. Antes de restaurar, Cortex Go guarda automáticamente otra copia de la base actual. Los respaldos no están cifrados; pueden conservar comentarios borrados y una restauración puede recuperarlos. Revisa la lista para borrar uno o todos los respaldos locales de Cortex Go.

Los respaldos se guardan en la carpeta local de datos de Cortex Go, dentro de backups. Trátalos como datos privados.
